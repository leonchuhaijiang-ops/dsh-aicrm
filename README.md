# dsh-sales · AI-CRM 客资管理系统

**给 B2B 销售用的本地优先看板插件**：客户和跟进记录就存在你自己选的一个目录里（两张 Excel 表），AI 长在 DSH 的对话与看板里，替你回答「今天该打给谁、开口怎么说、这个客户跟到哪一步了、这周到底发生了什么」。

不是一个 SaaS，不注册账号，不往云上传客户表。

```text
你说：今天该给谁打电话？
它说：8 个首次触达 + 5 个今日跟进，按优先级排好，每条带「为什么是今天」和开口话术。
      （数据来自你自己目录里的 销售客户-主表.xlsx）
```

---

## 为什么会有这个

大多数 CRM 对一线销售来说都太重：要么要先录入半天，要么数据锁在别人的服务器上，要么「智能」功能只是把同一份客户表换个表格渲染。

这个插件的取向相反：

- **Excel 就是数据库**。随时能用 Excel 打开、改、拷走；停用插件你的数据也不会消失。
- **AI 不是聊天框，是执行清单**。每个 AI 功能的输出都是「下一步做什么 + 为什么 + 怎么做」，不是一个更漂亮的总结。
- **数据留在本机**。客户表只在你指定的目录里，出网只有「调模型」这一条路，且带字段级脱敏。
- **规则先跑，AI 加强**。模型不通、超时、没配 key，功能全部回落到规则版，照样能用。

## 能干什么

| | |
|---|---|
| **今日作战队列** | 每天该打哪些电话：首次触达保底 10 条 + 今日跟进（到期/逾期/停滞/联售），日上限 25 条，每条给动作 + 原因 + 话术 |
| **客户全景与 SOP** | 一个客户的所有信息一屏看完；13 段销售漏斗（标品 7 段 + 企业级 6 段）看清楚走到哪、卡在哪 |
| **作战卡** | 「下一位客户我怎么跟」：现在最该做的一件事、为什么是今天（带具体数字）、打不通/说贵/说没需求怎么接 |
| **通话实时接话** | 电话外放时把客户刚说的话丢进来，给你 1–3 条「现在该接的那句」 |
| **记跟进** | 一句话落库：流水 + 主表状态/排期/阶段/等级一起更新，不用填表 |
| **点名结论** | 每个客户都要有个结果（沉默/暂缓/无法联系/终止/成交），**停跟必须有锚点**，堵住「挂了却不说为什么」的黑洞 |
| **飞轮与复盘** | 13 环体检（哪一环堵了、停滞几天）、周复盘（新增/推进/结论/黑洞/转介绍/瓶颈）、周战役三批触达话术 |
| **合同台账** | 合同要素、付款节点、状态流转；本机生成 `.docx`，规则初审提示风险 |
| **看板** | 侧边栏入口 + 全屏看板，9 个页签（今日任务 / 待首触 / 挂起冷备 / 待定跟进 / 重点跟进 / 标品成交 / 定制开发 / 合同管理 / 查询指导），AI 对话框在左侧，四套主题 |
| **查询指导** | 客户查询 + 销售指导合并页：按客户ID/公司/手机/微信找客户、看汇总与跟进建议 |

15 个模型工具 + 一个看板，完整清单见 **[docs/tools.md](docs/tools.md)**。

## 快速开始

前提：DSH 桌面端 0.2.x、Node.js ≥ 20。

```bash
# 1. 取代码 + 装依赖（运行时依赖只有两个：xlsx；fflate 仅用于压缩 .docx，缺失时自动走内置实现）
git clone <本仓库地址> dsh-sales
cd dsh-sales
npm install

# 2. 初始化数据目录（先 --check 干跑，确认再加 --yes）
node scripts/setup.mjs --data-dir "/home/you/sales-data" --check
node scripts/setup.mjs --data-dir "/home/you/sales-data" --yes

# 3. 自检（体检 + 隐私扫描 + 集成冒烟，全绿再开始录数据）
npm run check
npm run smoke
```

然后把 `dsh-sales` 目录装进 DSH：侧边栏「**插件**」→「**添加插件**」→「本地插件目录」→ 选仓库根 → 安装 → **托盘完全退出 DSH 再重启**。

重启后点侧边栏底部的销售入口，看板会带你走完首次设置（数据目录 → 模型通道 → 建表）。模型通道默认 `session`（跟随当前会话模型），**不需要 API key**。

> 详细步骤、常见失败原因、升级卸载：[docs/install.md](docs/install.md)

## 配置：一个 JSON，没有密钥

配置文件默认 `<home>/.dsh/sales.config.json`，三个概念：

| 配置 | 说明 |
|---|---|
| `dataDir` | 数据目录**绝对路径**。优先级：`SALE_DIR` 环境变量 > 配置文件 > 默认 `<home>/dsh-sales-data` |
| `ai.mode` | `session`（默认，跟随会话模型，零配置）/ `fixed`（钉死 provider+model）/ `local`（本机 Ollama，数据不出本机） |
| `features.rag` + `profile` | 是否让模型参考 `营销资料库/` 的语料；你的公司名/产品名（只用于让话术称呼对得上） |

插件**不持有任何 API key**：模型调用一律经 DSH 宿主，密钥由 DSH 管理。

完整字段与排错：[docs/configuration.md](docs/configuration.md)

## 数据模型：两张表

| 文件 | sheet | 列数 |
|---|---|---|
| `销售客户-主表.xlsx` | 客户主表 | 31 |
| （同一工作簿） | 联系人 | 5 |
| `销售客户-流水表.xlsx` | 跟进流水 | 11 |

列名是契约：**顺序可以调，列名不能改、不能删**。写入前会断言表头，对不上直接拒绝而不是静默清空。所有写入走唯一入口（写锁 + 表头断言 + 原子写 + 变更日志）。

列定义、枚举取值、目录结构：[docs/data-model.md](docs/data-model.md)

## 隐私

- 客户表、合同、日志**只在你指定的目录**；插件没有账号、没有云同步、没有埋点。
- 唯一出网口是「调 DSH 宿主里的模型」，发出去前做**字段级脱敏**（姓名/公司/手机/微信 → 带标签的占位符，回来再回填）。
- 内置出网闸门拦 8 类「agent 把表传出去」的动作（搜索带客户数据、curl/scp/npm publish、UNC 路径、编码混淆等）。
- **诚实声明**：这不是「绝对不出本机」。模型厂商仍是数据出口；自由文本里的客户自述遮不住；正则闸门拦不住分两步外传。想彻底不出网就用 `ai.mode=local`。

完整边界、做不到的地方、合规提醒：[docs/privacy.md](docs/privacy.md)

## FAQ

**第一次打开看板就让我做「首次设置」，是出错了吗？**
不是。没有配置数据目录时，看板会主动拉起三步向导（数据目录 → 模型通道 → 建表），HTTP 读接口同时返回 `{ok:false, code:'UNCONFIGURED'}`。走完向导就正常了。

**数据目录怎么换？**
看板标题栏「⚙ 设置」里改，或直接改配置档的 `dataDir`，或设环境变量 `SALE_DIR`。**旧数据不会自动搬**：把旧目录里的两张 `.xlsx`、`合同/`、`营销资料库/` 和几个 `.json` 复制到新目录，再跑一次 `node scripts/doctor.mjs` 确认。

**`session` / `fixed` / `local` 三种模型通道怎么选？**

| 模式 | 适合谁 | 代价 |
|---|---|---|
| `session`（默认） | 绝大多数人 | 零配置、不需要 API key，花的是你当前会话的额度 |
| `fixed` | 想固定用某个便宜/快的模型 | 要填 provider + model，密钥仍由 DSH 管理 |
| `local` | 客户数据一点不想出本机 | 要自己有本机模型（如 Ollama），质量与速度取决于本机 |

**模型挂了 / 超时 / 没配 key 会怎样？**
所有 AI 功能都有规则版兜底：返回 `{ok:false}` 并降级成规则输出，页面不会崩。台账 `logs/ai-calls.log` 只记用途、模型、耗时、字数、成败。

**客户表能放 OneDrive / 坚果云 / WPS 云盘吗？**
不建议。同步盘会在后台把整张表上传到第三方云，绕过本插件的所有边界。详见 [docs/privacy.md](docs/privacy.md)。

## 项目结构

```text
dsh/index.js     宿主半：15 个模型工具 + /sales/* 路由
dsh/client.js    页面半：侧边栏入口 + 全屏看板 + 通话记录台
lib/sales-lib.js 数据层：Excel 读写、SOP 引擎、派生视图（CJS CLI）
dsh/ai.js        唯一的模型出口（不持 key、不直连、失败必回落）
scripts/         setup / doctor / check-no-pii / smoke
templates/       示例营销语料
docs/            安装、配置、数据模型、工具、隐私、架构
```
