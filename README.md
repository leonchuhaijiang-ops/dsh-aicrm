# dsh-sales · AI-CRM 客资管理系统

给 B2B 销售（面向企业客户）用的本地优先看板插件：客户和跟进记录存在你自己选的一个目录里（两张 Excel 表），AI 长在 DSH 的对话与看板里，替你回答「今天该打给谁、开口怎么说、这个客户跟到哪一步了、这周到底发生了什么」。

不是一个 SaaS（在线订阅服务），不注册账号，不往云上传客户表。

```text
你说：今天该给谁打电话？
它说：8 个首次触达 + 5 个今日跟进，按优先级排好，每条带「为什么是今天」和开口话术。
      （数据来自你自己目录里的 销售客户-主表.xlsx）
```

## 能干什么

| | |
|---|---|
| **今日作战队列** | 每天该打哪些电话：首次触达保底 10 条 + 今日跟进（到期/逾期/停滞/联售），日上限 25 条，每条给动作 + 原因 + 话术 |
| **客户全景与 SOP** | 一个客户的所有信息一屏看完；13 段销售漏斗（标品 7 段 + 企业级 6 段），看清走到哪、卡在哪 |
| **作战卡** | 「下一位客户我怎么跟」：现在最该做的一件事、为什么是今天（带具体数字）、打不通/说贵/说没需求怎么接 |
| **通话实时接话** | 电话外放时把客户刚说的话丢进来，给你 1–3 条「现在该接的那句」 |
| **记跟进** | 一句话落库：流水 + 主表状态/排期/阶段/等级一起更新，不用填表 |
| **点名结论** | 每个客户都要有个结果（沉默/暂缓/无法联系/终止/成交），停跟必须有锚点（复查时间或信号） |
| **飞轮与复盘** | 13 环体检（哪一环堵了、停滞几天）、周复盘（新增/推进/结论/转介绍/瓶颈）、周战役三批触达话术 |
| **合同台账** | 合同要素、付款节点、状态流转；本机生成 `.docx`，规则初审提示风险 |
| **看板** | 侧边栏入口 + 全屏看板，9 个页签（今日任务 / 待首触 / 挂起冷备 / 待定跟进 / 重点跟进 / 标品成交 / 定制开发 / 合同管理 / 查询指导），AI 对话框在左侧，四套主题 |
| **查询指导** | 客户查询 + 销售指导合并页：按客户ID/公司/手机/微信找客户、看汇总与跟进建议 |

15 个模型工具 + 一个看板，完整清单见 [docs/tools.md](docs/tools.md)。

## 数据在哪

- 客户表、合同、日志只在你指定的那个目录里；插件没有账号、没有云同步、没有埋点。
- **这个仓库里只有工具**：源码、文档、4 份原创示例语料；不含任何真实客户表、备份、日志或密钥，作者也拿不到你的数据。
- 唯一出网口是「调用 DSH 宿主里的模型」，发出前做字段级脱敏（姓名/公司/手机/微信 → 带标签的占位符，回来再回填）；也可以切到本机模型，一步都不出本机。
- 不承诺「绝对不出本机」：模型厂商仍是数据出口，自由文本里的客户自述遮不住，细则见 [docs/privacy.md](docs/privacy.md)。
