# 示例语料（templates/营销资料库）

这个目录放的是**给新用户起步用的示例资料**，不是插件本身的一部分。它的作用有两个：

1. 让第一次跑 `node scripts/setup.mjs` 的人，数据目录里立刻就有可检索的语料，不会一打开就问「为什么搜不到东西」；
2. 给一套可以直接照抄的**格式样例**——Markdown 怎么写、结构化 JSON 长什么样。

> 全部内容为原创示例，仅用于演示资料格式与写作口径，不构成任何效果承诺，也不含真实客户信息。你可以随意改写、删除或替换成自己的资料。

## 目录内容

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `企业级 AI 落地要点.md` | Markdown | 企业级客户的判断信号、安全边界、落地路径与常见反对 |
| `销售异议处理示例-价格篇.md` | Markdown | 价格异议的分类、应对顺序与话术禁忌 |
| `设计院与咨询公司客户画像示例.md` | Markdown | 两类典型客户的组织、关心点、卡点与触达建议 |
| `销售技巧-结构化.json` | JSON | 10 条结构化销售技巧，供「技巧检索」按关键词打分 |

初始化时，`scripts/setup.mjs` 会把这里的 `.md` / `.json` 复制到 `<数据目录>/营销资料库/`。**只补缺，不覆盖**：数据目录里已经存在的同名文件会被保留，所以你改过的版本不会被示例盖掉。

---

## 怎么被使用

- Markdown 文件会被当作普通文本切片，用于资料检索（RAG）。文件名就是来源标识，建议起得能看懂，例如 `投标答疑常见问题.md`。
- `销售技巧-结构化.json` 是「技巧检索」的专用数据源，文件名固定，不要改。检索时按**标题 / 标签 / 摘要**做关键词匹配，`点赞量` 只在同分时参与排序。
- 语料目录为空时，检索会报「语料为空：营销资料库 里还没有可检索的 .md / .json」，补几个文件即可。

## Markdown 写法建议

没有强制格式，但这样写检索效果更好：

1. **一个文件只讲一个主题**，文件名用主题命名，别做「大杂烩」。
2. 开头两三行写清「这篇解决什么问题、适合谁看」，方便切片后仍能看出上下文。
3. 用小标题分层，每节控制在几段以内；单段太长会被切碎，语义容易断。
4. 涉及政策、标准、规范的，写清**文号与版本**；不确定的地方标「待核实」，不要把推测写成结论。
5. 不要放客户真名、联系方式、合同金额等敏感信息。

## 结构化 JSON 的字段契约

文件整体是一个**数组**，每个元素是一条技巧：

```json
[
  {
    "标题": "客户说「太贵了」时，先问这一句",
    "标签": ["价格异议", "需求确认", "提问"],
    "摘要": "一句话说清这条技巧解决什么问题。",
    "全文": "完整的正文，可以分几段。",
    "点赞量": 0
  }
]
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `标题` | 字符串 | 是 | 一句话标题，检索权重最高 |
| `标签` | 字符串数组 | 是 | 2–4 个关键词；**必须是数组**，写成逗号分隔的字符串会报错 |
| `摘要` | 字符串 | 是 | 一段话概括，参与检索 |
| `全文` | 字符串 | 是 | 正文，建议 200–400 字，讲清一个可执行的做法 |
| `点赞量` | 数字 | 否 | 默认 0；只用于同分排序，不参与相关度计算 |

新增条目直接往数组里追加即可。改完建议跑一次 `node scripts/doctor.mjs`，它会检查这个文件能否解析、条数是否正常。

## 自己补充语料时的三条要求

1. **脱敏**：去掉真实客户名、联系人、手机号、微信号、具体合同金额与可定位的項目细节。示例、抽象化的行业共性没有问题。
2. **原创或已获授权**：不要复制第三方付费课程、付费社群、书籍的原文。引用公开政策文件时注明文号；引用他人观点时注明来源。
3. **标清时效**：政策、标准、平台规则会变，写清版本或获取日期；拿不准的标「待核实」，别让读者把旧口径当现行规定。

## 边界与免责

- 示例中的应对方式、话术与流程是通用参考，**不承诺任何业务效果**；实际使用要结合自己的行业、客户与合规要求调整。
- 涉及设计院客户时，不得暗示 AI 可以替代施工图设计、结构计算或设计文件签章——这些必须由注册人员负责。
- 涉及咨询成果时，成果责任在咨询工程师（投资），工具只提供辅助。
- 涉及国资监管、招投标的项目，须按客户及其上级单位的合规要求执行；数据默认不出客户内网。

## 常见问题

**Q：我改了示例文件，重新跑 setup 会被覆盖吗？**
不会。数据目录里已存在的文件会保留，setup 只补齐缺失的。

**Q：能只放自己的资料、把示例删掉吗？**
可以。示例只是起步用的，删掉后记得至少留一两个 `.md`，否则检索会提示语料为空。

**Q：可以放子目录吗？**
可以。`营销资料库` 下的 `.md` / `.json` 会递归收集；建议按主题分子目录，例如 `营销资料库/行业资料/`。

**Q：JSON 写错了会怎样？**
检索时会读不出来。先用 `node scripts/doctor.mjs` 体检，它会指出解析失败，再回头检查括号与逗号。
